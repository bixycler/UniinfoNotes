# Fixes: title-resolution pipeline

## Fix A: PAT_REF in `resolveTitleReferences()` (already applied + verified)

`PAT_REF` in `common-utils.js:354` matched `((uuid))` inside `[text](((uuid)))`, causing corruption and false circular refs. Fixed with negative lookbehind `(?<!\]\() `.

## Fix B: `lastContentLine` fallback inheriting from sibling blocks

### Problem scope — only 2 functions affected

`lastContentLine` appears in **only** 2 functions across the entire codebase:
- `indexFileBlocks` in `build-index.js` (lines 60–84) — builds global index
- `indexInternalBlocks` in `logseqmd2commonmark.js` (lines 97–117) — per-file local override

**`convertFile` is NOT affected** — it has no `lastContentLine` variable. It handles `- id:: uuid` via its own `bulletPropMatch` regex at line 230, which is independent.

### The bug

Both index functions use a flat accumulator:
```js
let lastContentLine = basename;
// ...
if (idMatch) {
  title = content.replace(idMatch, '').trim(); // = "" for bare `- id:: uuid`
  blocks[uuid] = { title: title || lastContentLine, ... }; // inherits lastContentLine!
} else {
  lastContentLine = content || lastContentLine; // overwritten by ANY bullet, any level
}
```

Since `lastContentLine` is overwritten on EVERY non-id bullet regardless of nesting, a bare `- id:: uuid` at indent N can inherit content from a **sibling** at indent N, not its parent.

### Case 6 in test fixture — NOT affected

```
- 6. Blank Bullet...
	- id:: 66ea4711... ← child (deeper indent)
```
These ARE children of `- 6. Blank Bullet...`, so inheriting the parent's content is correct. The fix preserves this behavior — it only blocks inheritance from SIBLINGS (same indent).

### Fix

Change in both `indexFileBlocks` and `indexInternalBlocks`:

```js
let lastContentLine = path.basename(filePath, '.md');
let lastContentIndent = -1;

// ...in the loop, before strip:
const curIndent = line.length - line.trimStart().length;

// In the idMatch branch:
if (idMatch) {
  const uuid = idMatch[1];
  const title = content.replace(idMatch[0], '').trim();
  // Only fall back to lastContentLine if it's from a PARENT (shallower indent)
  const fallback = (title || '')
    || (lastContentIndent < curIndent ? lastContentLine : path.basename(filePath, '.md'));
  blocks[uuid] = { title: fallback, ... };
  if (title) {
    lastContentLine = title;
    lastContentIndent = curIndent;
  }
  // bare id:: does NOT update lastContentLine
}
```
