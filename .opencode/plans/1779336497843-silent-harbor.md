# Fixes: title-resolution pipeline + bare `- id::` block title transclusion

## Fix C: Full block-content transclusion for bare `- id::` blocks (in `indexLines`)

### Problem scope

When a Logseq block has no inline title (e.g. `- id:: uuid` with nothing between `- ` and `id::`), our current `indexLines()` falls back to the parent's `lastContentLine` or the filename as the block title. But Logseq itself treats all the content below the `- id::` line (the rest of the block) as the block title — blockquotes, `#+BEGIN_*` macros, properties, child bullets, code blocks, everything. This is the "transclusion/mirror" feature inherited from RemNote.

Currently these blocks' titles are all just filenames, losing the transcluded content:

| UUID | Actual block content | Current title (wrong) |
|------|-------------------|----------------------|
| `67baf59b-...` | `> 3blue1brown gives an excellent "mirror reflection" analogy...` | `"2025 Stories"` |
| `67850fd2-...` | `#+BEGIN_CAUTION` … `[:b ... " Back to WORK! "]` … `#+END_CAUTION` | `"Task"` |
| `66f6b7c0-...` | `search-scope-page:: [[Mind Jungle]]` … `collapsed:: true` | `"2024 Brainstorms"` |
| `66bad570-...` | `2. Theo nghĩa rộng hơn một chút,` … Vietnamese prose | `"2024 Stories"` |

### Solution

In `indexLines()`: when a `- id:: uuid` line has **no inline title** (`title` is empty after stripping `id:: uuid`), instead of immediately falling back to parent/filename, **look ahead** at subsequent lines to collect the full block content as the transcluded title.

**Algorithm** (inside the existing loop):

1. `i` is at a `- id:: uuid` line, `title` is empty (no inline text).
2. Scan forward from `i+1` to collect all lines until the next bullet at indent `<= curIndent` (i.e., the end of this block).
   — Skip `__CODE_BLOCK_` tokens, but expand them via `codeBlockMap` (original code lines join into the title).
   — Include everything: properties (`collapsed::`, `search-scope::`), blockquotes, `#+BEGIN_*` macros, raw text, continuation `id::` lines, child bullets.
3. Join the collected lines with `\n` → this is the block's title (full transclusion).
4. For `lastContentLine` inheritance: use the **first non‑property, non‑code‑block, non‑empty line** (so child blocks inherit a clean single-line parent title, not the entire multi-line block).
5. If no content lines found at all → existing fallback (parent `lastContentLine` or filename).

**`indexLines()` signature change**: accepts an optional 3rd parameter `codeBlockMap` (for expanding `__CODE_BLOCK_N__` tokens back to original source lines).

### Caller updates
- `build-index.js` `indexFileBlocks()`: pass `{ codeBlockMap }` from `preprocessCodeBlocks()` to `indexLines(filePath, cleanLines, codeBlockMap)`.
- `logseqmd2commonmark.js` `indexInternalBlocks()`: pass `codeBlockMap` from caller through to `indexLines()`.

### Example

Input:
```markdown
- id:: 67baf59b-...
  > 3blue1brown gives an excellent "mirror reflection" analogy…
  And it shows that light and the unithread is intrinsically straight…
```

Before: `title = "2025 Stories"` (filename fallback)  
After: `title = "> 3blue1brown gives an excellent "mirror reflection" analogy…\nAnd it shows that light and the unithread is intrinsically straight…"`

Subsequent `((67baf59b-...))` references resolve to this transcluded content, which may itself contain `((uuid))` refs that `resolveTitleReferences()` will recursively resolve — the true "mirror/transclusion" behavior.

## Fix B: `lastContentLine` fallback inheriting from sibling blocks

### Problem scope

The bug exists in the indexing loops of both `indexFileBlocks` (build-index.js) and `indexInternalBlocks` (logseqmd2commonmark.js). Instead of duplicating the fix, we extract ALL common logic shared between the two files into `common-utils.js`.

| 1 | Page-header normalization | `normalizePageHeader(rawLines)` | Identical in both files |
| 2 | Index loading (read JSON) | `loadIndex(indexFile)` | Nearly identical |
| 3 | Index saving (write JSON) | `saveIndex(indexFile, index)` | Nearly identical |
| 4 | CLI flag value parsing | `parseArgValue(args, i, flag)` | Repeated 5+ times |

### New functions in common-utils.js

#### 1. `normalizePageHeader(rawLines)`
Identical 10-line block in both files. Converts `# Heading` → `- # Heading`.

#### 2. `loadIndex(indexFile)`
Reads and parses `index.json`, returns the object. Both files have the same try/catch structure.

#### 3. `saveIndex(indexFile, index)`
Writes index JSON with dir creation. Both files do the same thing.

#### 4. `parseArgValue(args, i, flag)`
Eliminates the repetitive "check exists, resolve, error+exit" boilerplate that appears for `-o`, `-i`, `-b` flags. Returns `{ value, newIndex }`.

#### 5. `indexLines(filePath, cleanLines, codeBlockMap)` — the core fix

Core iteration logic with:
- Indent-aware `lastContentLine` fallback (sibling contamination fix).
- Full block-content transclusion for bare `- id::` blocks (Fix C).

```js
function indexLines(filePath, cleanLines, codeBlockMap) {
  const results = {};
  let lastContentLine = path.basename(filePath, '.md');
  let lastContentIndent = -1;

  for (let i = 0; i < cleanLines.length; i++) {
    const { line, originalIndex } = cleanLines[i];
    const curIndent = line.length - line.trimStart().length;
    const stripped = line.trim();

    if (stripped.startsWith('__CODE_BLOCK_')) continue;

    if (stripped.startsWith('- ')) {
      let content = stripped.substring(2).trim();
      const idMatch = content.match(PAT_ID_PROP);
      if (idMatch) {
        const uuid = idMatch[1];
        const title = content.replace(idMatch[0], '').trim();
        if (title) {
          // Inline title on the same line — normal case
          results[uuid] = { title, sourceLine: originalIndex + 1 };
          lastContentLine = title;
          lastContentIndent = curIndent;
        } else {
          // Bare - id:: with no inline title → transclude full block content
          const blockLines = [];
          let firstContentLine = '';
          for (let j = i + 1; j < cleanLines.length; j++) {
            const next = cleanLines[j];
            const nextIndent = next.line.length - next.line.trimStart().length;
            const nextStripped = next.line.trim();

            if (nextStripped.startsWith('- ') && nextIndent <= curIndent) break;

            if (nextStripped.startsWith('__CODE_BLOCK_') && codeBlockMap) {
              for (const cl of (codeBlockMap.get(nextStripped) || [])) {
                blockLines.push(cl);
              }
              if (!firstContentLine && codeBlockMap.has(nextStripped)) {
                const raw = codeBlockMap.get(nextStripped);
                firstContentLine = raw.find(l => l.trim()) || '';
              }
              continue;
            }
            if (nextStripped.startsWith('__CODE_BLOCK_')) continue;

            blockLines.push(next.line);

            if (!firstContentLine && nextStripped && !next.line.match(PAT_PROP)) {
              firstContentLine = nextStripped;
            }
          }

          const effectiveTitle = blockLines.length > 0
            ? blockLines.join('\n')
            : (lastContentIndent < curIndent ? lastContentLine : path.basename(filePath, '.md'));
          results[uuid] = { title: effectiveTitle, sourceLine: originalIndex + 1 };

          if (firstContentLine) {
            lastContentLine = firstContentLine;
            lastContentIndent = curIndent;
          }
        }
      } else {
        lastContentLine = content || lastContentLine;
        lastContentIndent = curIndent;
      }
    } else {
      const idMatch = stripped.match(PAT_ID_PROP);
      if (idMatch && lastContentLine) {
        results[idMatch[1]] = { title: lastContentLine, sourceLine: originalIndex + 1 };
      }
    }
  }
  return results;
}
```
