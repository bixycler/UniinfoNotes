# Fixes: title-resolution pipeline

## Fix A: PAT_REF in `resolveTitleReferences()` (already applied + verified)

`PAT_REF` in `common-utils.js:354` matched `((uuid))` inside `[text](((uuid)))`, causing corruption and false circular refs. Fixed with negative lookbehind `(?<!\]\() `.

## Fix B: `lastContentLine` fallback inheriting from sibling blocks

### Problem scope — only 2 functions, but same logic

The `lastContentLine` bug exists in **2 functions** with identical loop logic:
- `indexFileBlocks` in `build-index.js` (lines 40–101)
- `indexInternalBlocks` in `logseqmd2commonmark.js` (lines 93–133)

They differ only in output format (object with metadata vs flat map + lineMap). **`convertFile` is NOT affected** — it has no `lastContentLine` and uses its own `bulletPropMatch` regex.

### Fix: Extract shared `indexLines()` into common-utils.js

Instead of fixing two places, **extract the core iteration logic** into a new shared function `indexLines(filePath, cleanLines)` in `common-utils.js`, which returns `{ uuid: { title, sourceLine } }`. This function contains the indent-aware fix **once**. Then simplify both callers to just transform the output format.

#### Shared function (new, in common-utils.js):

```js
function indexLines(filePath, cleanLines) {
  const results = {};
  let lastContentLine = path.basename(filePath, '.md');
  let lastContentIndent = -1;

  for (let i = 0; i < cleanLines.length; i++) {
    const { line, originalIndex } = cleanLines[i];
    const curIndent = line.length - line.trimStart().length;
    const stripped = line.trim();

    if (stripped.startsWith('__CODE_BLOCK_')) continue;

    if (stripped.startsWith('- ')) {
      let content = stripped.substring(2).trim();
      const idMatch = content.match(PAT_ID_PROP);
      if (idMatch) {
        const uuid = idMatch[1];
        const title = content.replace(idMatch[0], '').trim();
        const effectiveTitle = title || (lastContentIndent < curIndent ? lastContentLine : path.basename(filePath, '.md'));
        results[uuid] = { title: effectiveTitle, sourceLine: originalIndex + 1 };
        if (title) {
          lastContentLine = title;
          lastContentIndent = curIndent;
        }
      } else {
        lastContentLine = content || lastContentLine;
        lastContentIndent = curIndent;
      }
    } else {
      const idMatch = stripped.match(PAT_ID_PROP);
      if (idMatch && lastContentLine) {
        results[idMatch[1]] = { title: lastContentLine, sourceLine: originalIndex + 1 };
      }
    }
  }
  return results;
}
```

#### Caller in build-index.js (simplified):

```js
function indexFileBlocks(filePath) {
  const blocks = {};
  try {
    const content = fs.readFileSync(filePath, 'utf8');
    let rawLines = content.split('\n');
    // ... page-header normalization ...
    const { cleanLines } = preprocessCodeBlocks(rawLines);
    const results = indexLines(filePath, cleanLines);
    for (const [uuid, entry] of Object.entries(results)) {
      blocks[uuid] = {
        title: entry.title,
        sourceFile: filePath,
        sourceLine: entry.sourceLine
      };
    }
  } catch (e) {
    console.error(`Error indexing blocks in ${filePath}:`, e);
  }
  return blocks;
}
```

#### Caller in logseqmd2commonmark.js (simplified):

```js
function indexInternalBlocks(filePath, cleanLines) {
  const mapping = {};
  const lineMap = {};
  try {
    const results = indexLines(filePath, cleanLines);
    for (const [uuid, entry] of Object.entries(results)) {
      mapping[uuid] = entry.title;
      lineMap[uuid] = { srcLine: entry.sourceLine, srcFile: filePath };
    }
  } catch (e) {
    console.error('Error indexing blocks:', e);
  }
  return { titleMap: mapping, lineMap };
}
```
